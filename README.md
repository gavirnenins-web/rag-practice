# RAG Practice Repository

A hands-on practice repository for learning Retrieval-Augmented Generation (RAG) without API keys or cloud services.

## Sessions

1. **Basics** - understand documents, queries, and context.
2. **Chunking** - split travel documents into useful chunks.
3. **Retrieval** - retrieve relevant chunks using simple keyword scoring.
4. **RAG Pipeline** - combine retrieval with a local rule-based answer generator.
5. **Agentic RAG** - practice deciding when retrieval is needed and using a simple tool flow.

## Requirements

- Python 3.10+
- Git
- No API keys required
- No external packages required

## Practice workflow

Create a branch for each session, make small commits, merge it into `main`, and inspect the history with `git log --oneline --graph --all`.
