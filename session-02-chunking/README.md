# Session 02 - Document Chunking

## Goal
Practice splitting a document into smaller chunks before retrieval.

## Task
1. Read `travel_guide.txt`.
2. Run `chunking.py`.
3. Change `CHUNK_SIZE`.
4. Observe how chunk size changes the retrieval units.

## Concept
Large documents are usually divided into smaller pieces so that retrieval can return focused context instead of an entire document.
