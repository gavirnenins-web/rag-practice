# Session 05 - Agentic RAG

## Goal
Practice the idea that an agent can decide whether it needs retrieval before answering.

The agent has two simple tools:

- `retrieve_travel_info()`
- `calculate_budget()`

## Task
Add another tool, such as `convert_currency()`, and make the agent choose the appropriate tool based on the query.

## Concept
This is a deliberately simple agent. The important practice is tool selection and control flow, not calling a real model.
